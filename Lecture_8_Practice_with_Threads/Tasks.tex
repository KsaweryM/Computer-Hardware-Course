\settitle{Lecture 8}{Practice with Threads}

Lecture 8 has no slides. It is a list of tasks to practise the concepts from Lecture 7: race conditions,
atomics, deadlock, condition variables, the producer-consumer problem and semaphores. Every task has a story,
the ready functions, the code and the questions. The code of each task is in its folder on GitHub,
for example \ghfolder{Task1}.

Tasks 6, 8, 9 and 11 start with an introduction to a new tool or problem: condition variables, the
producer-consumer problem, semaphores and the dining philosophers.
